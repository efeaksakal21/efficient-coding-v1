The aim of this project is to model the working principle of V1 neurons in the visual cortex of our brain when they try to perceive images using Sparse coding in a computer environment, and to compare it with another deep learning method, CNN

Technical details:
- Dataset: CIFAR-10
- Patch size: 8x8
- Sparse filters: 128
- Method: MiniBatchDictionaryLearning
- CNN: simple convolutional model
- Output: learned filters visualization
